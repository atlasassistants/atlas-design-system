Type

Poppins carries the voice: display, headings, eyebrows, and buttons. Outfit carries the reading: body, tables, forms, and UI text. The six roles below come from the guidelines (page 5); web sizes are an Atlas convention.

Rules

  • Three type sizes per screen, plus the eyebrow.
  • One accent phrase per headline: Vivid Purple on light, solid Yellow Green on dark. Never the whole headline.
  • Sentence case for web and product. Uppercase only for eyebrows and highlight text.
  • No third typeface. Monospace only for code and agent terminals.
  • The lowercase "atlas" wordmark lives only inside the logo files. Never set it in type.
