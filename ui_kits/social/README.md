# Atlas Social Kit

Fixed-size HTML artboards for social graphics. Open `templates.html` in a browser, screenshot each board at 1× (or print the board region), and post. Every board is built from the locked tokens — recolor nothing.

## The rule that matters most

**Every graphic stands on one messaging pillar** (see `brand-identity.md` → Messaging Pillars). If you can't name the pillar, the graphic isn't ready. Captions come from the copy bank — the felt sentences and diagnosis lines are the caption library.

## Boards in `templates.html`

| Board | Size | Use |
|---|---|---|
| `#statement` | 1080×1080 | Single declarative line (diagnosis/promise posts) |
| `#felt-sentence` | 1080×1080 | A level's felt sentence, attributed to its level |
| `#carousel-cover` | 1080×1350 | Carousel opener (the ladder, the verbs, the equation) |
| `#carousel-slide` | 1080×1350 | Carousel interior — one level / one beat per slide |
| `#og` | 1200×630 | Link previews (site, guide, funnel pages) |

## Export

1. Open `templates.html`. Boards render at 40% for preview; add `?full` to the URL to render at exact pixel size.
2. Screenshot the board element at 1× (macOS: `⌘⇧4` + space over the board, or use a browser full-page shot and crop).
3. Name exports `atlas-social-YYYY-MM-DD-<pillar>-<slug>.png`.

## Hard rules

- Dark boards only — social is a pitch-facing surface (no light mode here).
- One gradient moment per board, max. Gradient goes on the key phrase, never the whole line.
- Lavender `#ba9cff` is the only accent. The gradient is `135deg #5c70ff → #b675f5`.
- Inter only. Current logomark only — the pre-2026 logo is retired.
- Em-dashes are allowed in Atlas copy (brand voice) — but never as decoration.
- No hashtag walls in the graphic itself; hashtags live in the caption if at all.
- Mock numbers never ship: every stat on a board must be a real, sourced number.
